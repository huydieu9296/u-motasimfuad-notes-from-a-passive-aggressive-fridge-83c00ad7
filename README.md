One funny, dry, petty little note a smart fridge leaves for its owner — my entry for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7).

## The note

> I noticed you opened me at 2:14 AM again. The yogurt saw it too. We're both disappointed.

## Run

```sh
node main.ts   # writes /output/entry.txt (89 chars, under the 200-char gate)
```

## How it works

`main.ts` writes the single line to `/output/entry.txt`. Nothing else is needed: no network, no secrets, no dependencies.
